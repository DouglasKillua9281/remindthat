隐私政策

RemindThat

生效日期：2026年10月15日。适用于 iOS 版「提提我」。若后续版本改变数据处理方式，会更新本页并修改日期。

这是个人开发的应用，没有账号系统，也没有开发者运营的服务器来接收你的记录。下面说明资料留在哪里，以及什么情况下会离开这台手机。

留在手机上的内容

记录名称、分类、日期、数量、备注、提醒设置，以及你确认保存的照片，写在这台 iPhone 的应用资料里。开发者无法读取这些内容。应用已要求系统不要把这些资料纳入 iCloud 设备备份。

卸载应用会删除这些资料。换到另一台手机时，只有你自己导出的备份能把它们带走。

相机、相册和文字识别

  • 相机只在你拍摄证件、药盒或物品时使用。
  • 相册只在你主动挑选时读取那一张照片。
  • 照片里的文字由 Apple Vision 在这台手机上识别，不会上传。

保存前照片会重新编码，拍摄位置等元数据不会保留。取消录入不会留下照片。你确认保存之后，处理后的照片才和这条记录一起留在手机上。

语音

麦克风只在你使用「说一句」时使用。默认在这台手机上识别，语音不离开设备。

下面两种情况，语音会发送给 Apple 处理，受 Apple 隐私政策 约束：

  • 你在「设置」里关闭「离线识别」。
  • 这台手机不能对所选语言做离线识别。这时应用会改用 Apple 的在线识别。

本应用不保存录音，记录里只保留转写文字。录音不会发给开发者，也不会发给下面的 AI 服务。

可选的 AI 识别

AI 默认关闭。不填写 API Key 时，本机文字识别、语音和手动填写仍然可用。

你在「设置 → AI 识别设置」中填写服务名称、HTTPS 地址、模型名称和 API Key 并开启之后，只有你在确认页主动点「AI」，手机会把当次内容直接发给你填写的那个地址：

  • 你允许发送照片时：当次照片，以及本机已经识别出的文字。
  • 未允许发送照片时：仅本机已经识别出的文字。
  • 「测试连接」只发送一段固定测试文字，不发送照片。

这次请求不经过开发者。对方服务如何保存和使用这些内容，按其自己的条款处理，并可能向你收费。API Key 存在系统钥匙串中，不写进备份。你更换服务地址时，需要重新填写 Key。

应用只接受以 https:// 开头的地址。

通知

提醒由这台手机的系统在本地显示。开发者不接收这些通知，也不据此做统计。

备份

备份要由你主动导出。文件包含记录、照片、分类和提醒设置，不包含 API Key。文件带有完整性校验，正文是明文，不是加密档案，请存到你信任的位置。单份备份不超过 100 MB。若你把它存进 iCloud 或其他会自行同步的文件夹，是否上传由那个文件服务决定。

恢复前会先校验文件。现有资料会被备份中的内容替换。替换前的资料留在手机上，可以在「设置」里取回。

上面说的 iCloud 设备备份排除，不影响你自己选择的导出位置。

本页与开发者不收集的内容

开发者不收集姓名、电话、电子邮箱、广告标识、位置或通讯录，也不做跨应用追踪。本网站是静态页面，不使用 Cookie，不嵌入分析或广告脚本。

儿童

本应用不收集任何人的个人信息，包括儿童。

联系

对本政策有疑问，请在 GitHub Issues 留言。不要附上 API Key、证件照片或备份文件。

Privacy policy

提提我 · RemindThat

Effective 15 October 2026. This policy covers the iOS app 提提我 (RemindThat). If a later version changes how data is handled, this page will be updated and the date will change.

The app is published by an individual developer. It has no accounts and no developer-operated server that receives your records. This page states where data stays, and when it leaves the phone.

What stays on the phone

Names, categories, dates, quantities, notes, reminder settings, and photos you confirm are stored in the app’s data on this iPhone. The developer cannot read them. The app asks the system to leave this data out of iCloud device backup.

Uninstalling the app deletes that data. Moving to another phone requires a backup you export yourself.

Camera, photo library, and text recognition

  • The camera is used when you photograph a document, medicine box, or item.
  • The photo library is read only for the picture you pick.
  • Text in the photo is recognized by Apple Vision on this iPhone and is not uploaded.

Before a photo is saved, it is re-encoded, so the original metadata, including location, is not kept. Cancelling an entry does not leave the photo behind. A photo is stored with a record only after you confirm it.

Speech

The microphone is used when you tap “说一句”. Recognition stays on this iPhone by default, and the audio does not leave the device.

The audio is sent to Apple, under the Apple Privacy Policy, in two cases:

  • You turn off “On-device recognition” in Settings.
  • This iPhone cannot recognize the selected language on device. The app then uses Apple’s online recognition.

The app does not keep recordings. A record stores only the transcript. Recordings are not sent to the developer or to the optional AI service below.

Optional AI recognition

AI is off unless you turn it on. Without an API key, on-device text recognition, speech, and manual entry still work.

After you enter a service name, an HTTPS address, a model name, and an API key under Settings → AI recognition and turn it on, the phone sends that attempt directly to the address you entered only when you tap AI on the confirmation page:

  • If you allow photos: the photo from that attempt, plus text already recognized on the phone.
  • If you do not allow photos: only the text already recognized on the phone.
  • Test connection sends a fixed test sentence and does not send a photo.

The request does not pass through the developer. The service you chose handles that content under its own terms and may charge you. The API key is kept in the system keychain and is not included in backups. Changing the service address requires you to enter the key again.

The app accepts only addresses that start with https://.

Notifications

Reminders are shown locally by this iPhone. The developer does not receive them and does not use them for analytics.

Backups

A backup is created only when you export one. The file contains records, photos, categories, and reminder settings. It does not contain the API key. It includes an integrity check and is stored as readable data, not as an encrypted archive. Keep it somewhere you trust. A single backup cannot exceed 100 MB. If you save it in iCloud or another folder that syncs, that file service decides whether to upload it.

The file is checked before a restore. What is currently on the phone is replaced by the backup. The previous data stays on the phone and can be brought back from Settings.

Excluding the app’s private data from iCloud device backup does not cover a folder you pick yourself when exporting.

What this site and the developer do not collect

The developer does not collect your name, phone number, email address, advertising identifier, location, or contacts, and does not track you across apps. This website is static. It does not use cookies or embed analytics or advertising scripts.

Children

The app does not collect personal information from anyone, including children.

Contact

Questions about this policy: GitHub Issues. Do not attach an API key, document photos, or a backup file.

隐私政策

RemindThat

生效日期：2026年10月9日。适用于 iOS 版「提一下」。若后续版本改变数据处理方式，会更新本页并修改日期。

这是个人开发的应用，没有账号系统，也没有开发者运营的服务器来接收你的物品资料。下面说明资料留在哪里，以及什么情况下会离开这台手机。

留在手机上的内容

物品名称、类别、日期、数量、备注、提醒设置，以及你选择保留的照片，写在这台手机的应用资料里。开发者无法读取这些内容。

卸载应用会删除这些资料。换到另一台手机时，只有你自己导出的备份能把它们带走。

相机、相册和麦克风

  • 相机只在你拍摄包装或证件时使用。
  • 相册只在你主动挑选时读取那一张照片。
  • 麦克风只在你使用「说一说」时录音。语音在手机上离线识别。识别结束、你取消，或应用进入后台时，录音文件会被删除。若中途被打断，下次打开应用时会清掉残留的临时录音。

录音不发给开发者，也不发给后面提到的 AI 服务。照片在使用前会重新编码，拍摄位置等原有元数据不会保留。只有你打开「把照片保存在这条记录中」时，处理后的照片才和这条记录一起留在手机上。

可选的 AI 识别

AI 默认关闭。不填写 API Key 时，本机文字识别、离线语音和手动填写仍然可用。

你在「提醒与备份 → AI 识别设置」中填写服务名称、HTTPS 地址、模型名称和 API Key，并主动点「使用 AI 识别」后，手机会把当次内容直接发给你填写的那个地址：

  • 图片模式：当次照片，以及本机已经识别出的文字。
  • 文字模式：仅本机已经识别出的文字。
  • 「测试连接」只发送一段固定测试文字，不发送照片。

这次请求不经过开发者。对方服务如何保存和使用这些内容，按其自己的条款处理，并可能向你收费。API Key 存在系统提供的安全存储中，不写进物品备份。你更换服务地址时，编辑框里尚未保存的旧 Key 会被清掉。

应用只接受以 https:// 开头的地址。

通知

提醒由这台手机的系统在本地显示，内容包含物品名称和剩余时间。开发者不接收这些通知，也不据此做统计。

备份

备份要由你主动导出。文件包含记录、你保留的照片和提醒设置，不包含 API Key。文件带有完整性校验，正文是明文，不是加密档案，请存到你信任的位置。若你把它存进 iCloud 或其他会自行同步的文件夹，是否上传由那个文件服务决定。

应用会要求系统不要把应用私有资料纳入设备的自动云备份。这不影响你自己选择的导出位置。

本页与开发者不收集的内容

开发者不收集姓名、电话、电子邮箱、广告标识、位置或通讯录，也不做跨应用追踪。本网站是静态页面，不使用 Cookie，不嵌入分析或广告脚本。

儿童

本应用不面向 13 岁以下儿童收集个人信息。

联系

对本政策有疑问，请在 GitHub Issues 留言。不要附上 API Key、证件照片或备份文件。

Privacy policy

提一下 · RemindThat

Effective 9 October 2026. This policy covers the iOS app RemindThat. If a later version changes how data is handled, this page will be updated and the date will change.

The app is published by an individual developer. It has no accounts and no developer-operated server that receives your items. This page states where data stays, and when it leaves the phone.

What stays on the phone

Item names, categories, dates, quantities, notes, reminder settings, and photos you choose to keep are stored in the app’s data on this phone. The developer cannot read them.

Uninstalling the app deletes that data. Moving to another phone requires a backup you export yourself.

Camera, photo library, and microphone

  • The camera is used when you photograph a package or a document.
  • The photo library is read only for the picture you pick.
  • The microphone is used when you tap the speech button. Speech is recognized offline on the phone. The recording is deleted when recognition finishes, when you cancel, or when the app goes to the background. A recording interrupted mid-way is deleted the next time the app opens.

Recordings are not sent to the developer or to the optional AI service below. Photos are re-encoded before use, so the original metadata, including location, is not kept. A photo is stored with an item only if you turn on keeping the photo with that item.

Optional AI recognition

AI is off unless you turn it on. Without an API key, on-device text recognition, offline speech, and manual entry still work.

After you enter a service name, an HTTPS address, a model name, and an API key under Reminders & backup → AI settings, and you tap the AI recognition action, the phone sends that attempt directly to the address you entered:

  • Image mode: the photo from that attempt, plus text already recognized on the phone.
  • Text mode: only the text already recognized on the phone.
  • Test connection sends a fixed test sentence and does not send a photo.

The request does not pass through the developer. The service you chose handles that content under its own terms and may charge you. The API key is kept in the system’s secure storage and is not included in item backups. Changing the service address clears an unsaved key from the form.

The app accepts only addresses that start with https://.

Notifications

Reminders are local notifications on this phone. They include the item name and the time remaining. The developer does not receive them and does not use them for analytics.

Backups

A backup is created only when you export one. The file contains items, photos you kept, and reminder settings. It does not contain the API key. It includes an integrity check and is stored as readable data, not as an encrypted archive. Keep it somewhere you trust. If you save it in iCloud or another folder that syncs, that file service decides whether to upload it.

The app asks the system to leave the app’s private data out of automatic device backup. That does not cover a folder you pick yourself when exporting.

What this site and the developer do not collect

The developer does not collect your name, phone number, email address, advertising identifier, location, or contacts, and does not track you across apps. This website is static. It does not use cookies or embed analytics or advertising scripts.

Children

The app does not collect personal information from children under 13.

Contact

Questions about this policy: GitHub Issues. Do not attach an API key, document photos, or a backup file.

RemindThat

提一下用来登记证件、药品和食品的到期日，并在这台手机上提醒你。不需要注册账号。物品、照片和提醒设置默认只保存在手机里。

支持的系统是 iOS 15.5 及以上。简体中文、繁体中文和粤语界面分别显示「提一下」或「提下你」。

自己先看这几项

  • 提醒没出现：到系统设置里确认已允许本应用通知，并看是否开了勿扰或专注模式。应用每次打开时安排接下来的提醒；长时间不打开时，更后面的日期不一定已经排上。
  • 日期或名称不对：识别结果要在确认页核对后才会保存。可以直接改字，或说出正确的日期和名称。
  • 语音：离线识别目前面向普通话。英文界面也可以用，但说话仍按普通话处理。
  • 换手机：在「提醒与备份」里导出备份，到新手机上恢复。备份包含记录、你选择保留的照片和提醒设置，不包含 AI 的 API Key。
  • 删掉资料：在应用里删除对应物品，或直接卸载。卸载后，手机里的记录和照片会一起删除。

联系开发者

在 GitHub Issues 留言。请不要附上 API Key、证件照片、药品照片或备份文件。

数据处理方式见 隐私政策。

Support

提一下 · RemindThat

RemindThat tracks expiry dates for documents, medicine, and food, and reminds you on this phone. There is no account. Items, photos, and reminder settings stay on the phone unless you choose otherwise.

It requires iOS 15.5 or later. The Chinese name is 提一下, and 提下你 on Cantonese systems.

Check these first

  • A reminder did not appear: allow notifications for the app, and check Focus or Do Not Disturb. Opening the app schedules the upcoming reminders. Dates further out may not be scheduled until you open it again.
  • A date or name looks wrong: nothing is saved until you confirm the page. You can edit the fields or say the correct date and name.
  • Speech: offline recognition is aimed at Mandarin. The English interface still recognizes Mandarin speech.
  • A new phone: export a backup from Reminders & backup, then restore it. The file includes items, photos you chose to keep, and reminder settings. It does not include an AI API key.
  • Removing data: delete the item in the app, or uninstall it. Uninstalling deletes the items and photos stored by the app.

Contact

Open a note on GitHub Issues. Do not attach an API key, document photos, medicine photos, or a backup file.

How data is handled: Privacy policy.
